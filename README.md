# Research Paper Intelligence Platform

An evaluation-driven AI research assistant built using
Retrieval-Augmented Generation (RAG).

## Project Overview

The platform retrieves information from scientific research
papers and generates evidence-grounded answers with
verifiable citations.

## Core Technologies

- Python 3.11
- FastAPI
- Qdrant
- Sentence Transformers
- BM25
- Cross-Encoder Reranking
- Ollama
- Google Gemini API
- RAGAS
- Docker
